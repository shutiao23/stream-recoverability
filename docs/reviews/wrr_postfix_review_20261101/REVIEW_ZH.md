[revision_table_spec.py:161](../../../scripts/revision_table_spec.py#L161)把`case_designs.csv`的masks称为“JSON list of masked years”。实际1,623条都是JSON对象，例如：

```json
{"2010": "349:6", "2012": "358:6"}
```

对象键是年份，值包含日内掩膜区段编码；它并不是单纯年份列表。建议明确对象结构、零起点日序号、长度单位，以及多区段如何编码，并给一个小例子。

| 字段 | 应声明的单位 |
|---|---|
| estimate_error、year_set_error、reconstruction_error、reference_slope | °C/十年 |
| 三个MSE、cross_term、iid_linear_expected_year_set_mse | (°C/十年)² |

| weight_distance_squared | 十年⁻² |
| slope_sign_disagreement | 确定性规则为0/1；uniform_exact为无量纲条件期望 |

这样才能清楚对应`σ² × ||d||²`的量纲。这些是文档与可复用性问题，没有证据表明当前计算把单位用错。[字段审计](../../../results/wrr_postfix_review_20261101/table_metadata.json)
