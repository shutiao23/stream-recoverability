# H30 审稿补充分析与下一轮确认研究

本轮把附件中的工作分成当前稿件的证据补充和下一项研究的确认协议。当前主要用途确定为交付年度 H30 数值；热年标签用于检验用途错位，成本仍是实验参数。所有新增分析都使用已经查看过的数据，属于补充开发证据，不能重新称为盲测。

后续依据用户提供的写作风格报告完成了 [主稿论证与文字改写](STYLE_REWRITE_ZH.md)，更新标题、摘要、引言、方法组织、结果顺序、讨论、结论和图注。当前 PDF 已同步重建。

- `380_wrr_event_and_procedure.py`：区域代理与前向热事件留出；四格模型重新拟合学习、校准和评价的整流程重抽样。
- `381_wrr_external_cost_baselines.py`：在原瑞士候选池上比较全部重建、未知、热、冷、同留存随机拒绝、原冻结数值筛选和热概率成本决策。

## 物理解释的证据边界

CH_2327 对应 Dischmabach–Davos, Kriegsmatte。FOEN 官方资料确认该站流域约 43 平方公里、站点海拔 1671 米、冰川比例 0.7%。这些属性不证明调控、地下水或湖泊影响。资料中的雪比例按百分数解释，不把国家或海拔替代过程标签。[FOEN 站点资料](https://www.hydrodaten.admin.ch/en/seen-und-fluesse/stations/2327)

原 F0 中该站 16 次准入失败全部低估 H30，15 次采用空气温度重建。逐缺口偏差和流量关联支持进一步检验持续热偏移与空气代理失配；它们不能识别某一单独水文原因。瑞士河温研究说明流量、融雪和湖泊可能改变温度响应，但不能据此为本研究单站贴上未经核实的原因标签。[Michel 等 2020](https://hess.copernicus.org/articles/24/115/2020/index.html)

## 复现顺序

先运行 374 的两个协议，再运行 375 的诊断和两个 `--rebuild-source-no-donors`，随后运行 376、377。378 使用外部 crossed 案例；校准角色首次运行前执行 358，物理和 CSDI 校准参照分别执行 362 与 361。379 在所有重建角色齐备后运行。380 的整流程重抽样与 381 的成本基线不修改旧预测。

主文与 SI 的新增数字由结果表生成。原确认研究、补充开发和未来确认规格在措辞与表格中分别标识。

可用 `make wrr-followup` 按顺序复现原补充和扩展实验，`make wrr-followup-evidence` 使用已经完成的结果重建当前正文／SI／回复 PDF，`make wrr-followup-check` 检查新分析和原冻结锁。完整流程重抽样每种协议为 1,000 次；重新执行时复用已完成的任务。

扩展实验按 `make -j2 wrr-probability-budget`、`make wrr-joint-power`、`make wrr-backup-resource`、`make wrr-extended-evidence` 运行。概率训练会保留已完成的模型；三角色评估与短历史评估使用按旧留出组规则选出的唯一配置。供应方原始记录、逐案例缓存和训练临时文件保留在本地并可再生，紧凑证据及模型检查点保留在结果目录。

本次长推断另用 `392_wrr_probability_backfill.py` 调度尚未完成的尾部案例块，与三个角色的标准推断并行。它先重建相同输入并与各角色已完成块核对一致，然后以同一模型、种子和 390 的原采样函数补齐缓存；不改变样本、情景数、扩散步骤或输出。常规顺序复现不依赖这个运行优化。具体工作进程数和输入一致性核对保存在 `probability_development/parallel_backfill_contract.json`。
