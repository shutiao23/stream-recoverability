# H30 当前修稿结果与后续确认边界

当前论文的前三条贡献已经集中为目标诊断、窗口表示的增量证据，以及校准迁移和用途限制。附件要求优先完成的四格学习目标对照、用途匹配决策和集中失效诊断均已实际运行；结果不支持把原窗口设计写成已经证实优越的方法。

所有新增概率与轨迹模型都属于补充开发。状态残差原型改善了部分共同子集上的情景质量，但有显式不可用案例，未验证新总体的可靠覆盖。固定 CSDI 的有限配置也不代表概率补全上限。

概率参照另外获得同预算开发：两个水温／气温 CSDI 配置使用相同的 3,469 个旧源域训练站年、30 个按共享记录分组的留出组和每组五种任务掩码。配置选择只使用旧源域 H30 CRPS。新增系统向三个数值重建方法提供同一完整目标分布，先计算相对于各自交付点的原生失败概率，再比较直接概率与附加窗口头，避免遗漏强直接对照。具体配置和测试表现见生成的 S36、S37、S41；它们仍是已打开资料上的开发证据。

系统比较重新学习每种重建自身的误差并校准准入。报告保留共同可用子集的匹配误差，同时将全部 945 个瑞士受控候选中的不可用重建记为未知、计入用途损失，避免强迫资料不足的案例从分母消失。

联合样本规划已经重新拟合学习、校准和评价，共 3,000 次双模型重拟合、336 个预算格。主要规则同时要求两个方法的风险证据和五点增益的 Hoeffding 下界；最大联合成功率估计为 3.9%，正态近似敏感性最大为 13.1%，没有格子支持 80% 目标。实际源域训练／校准／测试仅有 59／21／24 组，大预算是对各角色有限经验分布的模拟抽样。结果不支持给出招募样本量，也不能直接规划新神经候选或未见水文类型。

另已为新神经点补做三方法、双参照的全流程规划：3,000 次完整头重拟合、重新校准与评价，覆盖 432 个预算格。所有格子在各自 1,000 次重复中均为零次联合成功；点别 95% Monte Carlo 上界为 0.37%，432 格同时上界为 0.97%，而非证明真实功效为零。实际旧瑞士支持只有 11／9／7 组，概率重建器按 F2 规格保持冻结；本次不能给新总体推荐招募量。结果和假设已进入 SI 表 S44，原双模型实验继续单独保留。

公开 DFO 备用记录经过元数据预锁与传感器一致性核查：180 个候选传感器对站年，没有一个符合原定三完整历史年要求。只有三个参考对因历史不足单独排除，对应两个短历史记录。它们的四个日均缺额均在冬季，仍有 8–19 个小时观测，暖季峰窗完整；这些案例中的零 H30 误差不能证明困难热峰恢复。Air2stream 不可用案例单列，未计为零误差。项目日聚合、单一省域依赖和非整日故障均在表 S39–S40 明示。

备用记录冻结的是元数据候选、采样／一致性阈值和历史要求。实现随后修正了移动记录器的坐标缓存键，以及有效观测与缺失重复值并存时的处理；规则没有放宽，也未按重建误差选案例。后续小时记录核对进一步澄清了“日均不足”而非“整日故障”，三组额外参考仍全部保留。初始锁和当前实现的区别见 [实现修订记录](../../../results/wrr_submission_ready/followup_20261021/completion/natural_implementation_corrections.json)。
