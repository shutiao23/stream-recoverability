# 新确认与真实缺测资料接入要求

当前没有可立即用于新确认的未查看独立样本，也没有满足原历史支持范围的真实长缺测备份参考。用户确认没有额外备用或有成本资料；公开 DFO 资源的资格核查为零，两个冬季日均不足记录仅作短历史敏感性。以下是待资料到位后的接入要求，不是已取得数据或已完成实验。

后续已从澳大利亚免登录公开接口取得 148 站日均记录，并核查 869 个原始采样站年。80 个候选站年通过日均质量与采样支持检查；开发、校准、测试分别来自 20、16、10 个流域组件。它们仍未满足正式确认的样本与独立性释放要求，当时 F2 专属测试的状态记录为未打开，其他模型随后对同一批站年的使用见招募记录更新。[实际资料接入、固定时点与剩余条件](NEW_REFERENCE_RECRUITMENT_ZH.md) 单独记录，未把资料资格当成方法胜出或真实缺测验证。

随后继续检索免登录来源，已取得七站 USGS 双通道记录，25 个候选站年均未通过全部参考要求；NEON 公开研究者归档的 PRT 目录可读，独立数字温度计配对记录尚未取得。[来源核查与限制](PUBLIC_SOURCES_ZH.md) 保留具体排除依据。用户没有 NEON 令牌，无需重复索取。

## 需要资料方提供什么

1. 原始水温序列、时间与时区、测量单位、站点／记录器／传感器标识、原始质量标志和监测起止日期。需要完整序列，不能用已计算的年度最高温或 H30 替代。
2. 与主记录区分的备用传感器序列，以及位置、深度、独立记录链和部署关系说明。备用值必须覆盖主记录的真实缺测日；主记录已观测日与备用缺测日共同组成完整的记录参考年。多个备用参考不算多个独立主站年。
3. 严格在目标年前、主记录本身的至少三个完整历史年。不能用备用真值填好历史后，冒充原流程的主记录历史支持。达不到条件的记录保留为单独的短历史研究，不修改原主要总体。
4. 缺测原因、设备故障／欠采样／开始或结束部署的区别，以及水体是否仍存在。不能把没有监测的时期当作故障；干涸或探头暴露空气时先核查水温指标是否有定义。
5. 可核实的流域边界和共享记录关系，以及冰雪、湖泊、地下水和调控属性的资料来源与生效日期。未知属性保留未知，不以国家、海拔或模型误差反推过程类型。
6. 数据使用与再分发条款、永久来源链接、版本和实际获取时间。若确有整理／获取成本，提供实际费用、工时与交付内容；免费可用资料直接使用，不人为隐藏。

提供方认证的日均值需有统计定义与质量说明。自行从小时值聚合时，沿用预定 UTC 日、至少 20 个不同小时且跨度至少 20 小时、冲突重复值不取平均等规则。传感器对需至少 90 个可比观测日，日均差 MAE 不超过 0.25°C、绝对差 95 分位不超过 0.5°C。这些只是项目的记录参考资格，不等于零传感器误差或生态真值保证。

收集全部合格缺测年份并记录排除理由。可按预先定义的暖季／长缺口层安排覆盖，但不能在看到重建误差后挑案例，也不能以暖季压力样本估计整个档案的自然故障比例。DFO 已发现的冬季部分小时不足不能替代暖季长故障验证。

## 打开目标结果之前

先填写 [元数据模板](new_sample_metadata_template.csv)，只使用来源、身份、部署、时间覆盖和已核实过程资料。历史完整年数的元数据估计与最终质量核查须分开。将站点别名和全部共享目标／邻站记录与既有输入清单比对，排除连接的旧记录；再按流域、共享资料与区域事件关系划分开发、校准和测试角色。

冻结主要候选、原生 CDF 与匹配提升树两个直接参照、原始候选分母、误差容限、风险与五点实用增益的联合规则。候选必须分别面对两个参照，不能事后挑较弱者。三个方法与两个增益比较共享错误预算。既有双模型源域规划不覆盖这套未来程序；在候选和部署抽样模型确定后，需要相应联合功效规划，不能把 59／118 组例子当成招募数量。

真实故障验证、人工机制掩码和日历回放分别建表。记录实际独立组件、站年、热事件及重复掩码数；更多掩码不补足独立组。所有预定测试组保留，不按表现移除。资料质量排除按冻结规则执行并留痕。
