# Calendar-time backtest qualification

The strictly_prior_years protocol recomputes every local thermal input from
earlier calendar years, fits/calibrates the global head through 2018 and
evaluates 2019--2022. The two predictive freezes and all inputs remain unchanged.

This is a forward hindcast using current-vintage observations and reanalysis,
not a prospective field trial or an archived as-of-2018 operational replay.
Historical publication, quality-revision and reanalysis-release vintages were
not preserved. Calendar dates alone cannot establish when a particular product
was available to an agency.

Final prose and figure labels make this limitation explicit. Earlier compact
table labels using Prospective refer only to the full calendar-time information
cutoff. No timing qualification is used to rescue a failed test result or to
change the original model, threshold, role, tolerance, margin or data.
