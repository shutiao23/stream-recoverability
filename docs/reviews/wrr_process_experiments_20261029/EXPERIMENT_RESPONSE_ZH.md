## C：实际来源重校准的范围与结果

原来源区间校准正权并集有2,370个掩码案例、19站、102个唯一站年。FOEN模型使用1,142案例、11站、4个正权连接群组，重复权重合计2,899；Bavaria模型使用1,228案例、8站、4个正权群组，权重合计2,242。原分配角色中的群组数与抽样后正权群组数不同，不可混列。来源年均在2009年及以前，与相应目标群组分离。每单元原规则仍是至少50个有限正权案例才使用该单元，否则回退到整个正权来源池；50不是加权行数门槛。

2,370来源案例与27目标案例的原生20条轨迹及七分位数均复现原保存值，记录的最大绝对差为0。7,110个来源案例×种子可用性记录均保持可用；`source_unavailable_cases.csv`为有表头的零行台账。288个地区×seed×预算×校准单元的偏移向量中，189个至少一个偏移相对历史原生20条偏移改变超过0.05°C。这不是“189个独立站点”。

下表在同一27例上按案例等权汇总；数值来自`target_historical_reference.csv`和`target_three_layer_cases.csv`。

| 参考/实现 | MAE（°C） | 公共256点正态间距CRPS（°C） |
|---|---:|---:|
| 固定D2历史参考 | 0.114993 | 0.086699 |
| 历史原生20条、历史来源偏移 | 0.133482 | 0.087948 |
| seed 0、500条、重估来源偏移 | 0.115847 | 0.078668 |
| seed 1、500条、重估来源偏移 | 0.110820 | 0.078536 |
| seed 2、500条、重估来源偏移 | 0.110017 | 0.076225 |

MAE排序随实现改变，CRPS相对历史参考也改变方向。更直接地，在固定seed 0且同为重估来源偏移的嵌套比较中，20条CRPS为0.087647、500条为0.078668，跨越固定D2的0.086699；这项同随机流预算对比不混用native20与nested20。不能将这些小差异转为普遍方法优劣。历史原生20条与新嵌套路径的比较同时包含随机实现、预算和校准变化；要检查单个阶段，应使用相同seed/目标轨迹的三层表及阶段对比，而不是把历史到500条的全部变化归因于预算。

重校准层的`nested20→500`上端绝对变化中位数，瑞士在三个seed为0.0691、0.1169、0.1024°C，Bavaria为0.0609、0.1011、0.0670°C。瑞士原来较稳定的未校准结果不能代表重新估计来源偏移后的尾部。目标仍只有两个连接群组，且每地区一个群组；地区、重建器和群组未被分离。当前实验没有重新评分全档案趋势，也未证明500条足够。

来源校准另有当前内容冻结的封闭重放：141项依赖加清单本身，共142个文件，包含102个来源站年NPZ、27个目标NPZ和最小原生来源/目标参考等。默认975入口不读取原日面板、原case cache或joblib。现有重放收据记录主工作区及仅该闭包的临时副本均重现21,330行来源预算分位数、288组偏移及729行目标评分，记录最大差为0。这证明当前冻结参数的数值重放，不补造历史hash身份，也不证明原始数据处理或模型拟合可由该小包重建。

976在临时副本中调用原`968.analyse_full`四次，未禁用校准保护。目标真值置乱或统一加1时，729行评分改变而288组来源偏移逐字节不变；来源真值加1的正控使2,016个偏移标量相应加1，并改变243行重新校准目标分布，未校准/固定旧偏移两层保持不变。19个正式结果文件的hash保持不变。此探针只覆盖年度校准与评分接口的评价真值污染，不是修改原始隐藏水温日后重新拟合上游日模型的检验。

## B：更强同数控制改变了哪些判断

主分析使用805个实际遮挡共同档案，17个连接群组。以下为档案等权、对照减暖季的10,000次配对群组重采样；本轮bootstrap seed为2026102969。

| 策略 | RMSE（°C/十年） | RMSE差的95%群组区间 |
|---|---:|---:|
| 暖季90% | 0.445884 | — |
| 旧一次随机 | 0.454013 | [−0.010343, +0.017669] |
| 旧仅新增年均衡 | 0.456635 | [−0.006252, +0.040391] |
| 精确均匀随机策略期望 | 0.449225 | [−0.005204, +0.017087] |
| 包含固定完整年的CDF优化 | 0.428370 | [−0.027356, −0.004873] |
| 包含固定完整年的Sxx优化 | 0.402260 | [−0.064466, −0.017267] |
| 全保留 | 0.169685 | [−0.355673, −0.184140] |

在468个可选择档案中，暖季/CDF/Sxx的RMSE为0.394372/0.359434/0.303130。三种跨档案权重均保留两个较强控制的改善方向；逐一删去17群组的次级固定预测检查也没有改变该方向。删群检查是在看到新控制结果后加入，不能冒充事前确认。

200个随机实现的平均RMSE为0.450527，同一200次MSE平均后开根号为0.450611；精确枚举得到的`√E[MSE]`为0.449225。前两个是有限200次Monte Carlo摘要，不能拿它们与精确值的差当作策略偏差；跨seed的2.5%–97.5%范围0.435855–0.467081描述选集变异。200次中62次RMSE低于暖季，不构成等效性或因果检验。

820个原始档案中，13个暖季仅保留3或4年，按原至少五年条件不进入807共同队列。它们的全保留RMSE为0.339042；全820个全保留RMSE为0.173460。该分母差反映可用性选择，不能把不同分母的误差作同一配对对比。807中的两例零遮挡，保存误差为0；805主队列将它们明确单列。

因此可以说：在本有限记录目标上，全保留仍最接近目标；同数规则的时间放置也会产生可观察的改进。不能继续用旧弱控制排除位置/杠杆作用，也不能据此声称纯数量效应已识别。

## 实际日期重叠与A/水关系的新影响检查

年度最长缺口主比较完整重现：2010–2025观测109站年，中位4天、≥30天11.93%；经验日历3,806站年×重复，中位6天、10.25%；控制缺口3,777站年×重复，中位60天、100%。1981–2025观测补充为220站年，中位3天、11.36%。

2010后109个观测不完整站年中，74个具有另一同群可评价队列站，35个从新同日分母中排除。在这74个中，同年有缺测为38个（51.35%），实际同日有共同缺测为14个（18.92%）；共享缺测站日为40/2,086（1.92%）。经验日历的对应peer分母为2,810、排除996，站年同日重叠36.01%、共享缺测站日11.92%；控制缺口为2,779、排除998，分别58.58%与38.68%。这些条件分母与旧全部109站年的shared-year 34.86%不同，不能互换。

地区几何标准化的删群覆盖差为+12.392至+17.772个百分点；加入重建器的共同支持差可到−1.120个百分点，有两次反向。Bavaria站内年度水气斜率前后变化在站年等权下为−0.005385，等站点总权重下为−0.034290，删群范围为−0.088226至+0.108920。FOEN仅两群组，删除主要群组后会只剩一站。它们是解释边界的证据，不支持重建器因果归因或日尺度关系稳定。

## 数值积分与缓存边界的最后核对

`979_crps_grid_sensitivity.py`固定783个已保存年度分布，将CRPS积分点从256增至1,024及4,096。独立order-statistic公式复现原256点分数，最大差约1.12e-14；单案例256→4096的最大变化为0.0000628°C。固定seed 0的nested20/500与固定D2之间的CRPS排序在三个网格下相同。这只检查既定七分位数及外尾假设的积分精度，不证明年度真实分布或无限轨迹收敛。

来源重构缓存另外绑定天气输入、配置、实际加载参数、站点身份/索引、日模型/AR1/随机种子代码及运行库版本。旧缓存缺签名时被拒绝；通过无resume实际重构后才写入新签名。输入变化拒绝测试和重构前后数值一致性由`source_calibration/resume_signature_rebuild_verification.json`记录，不能把补签名替代重建。
