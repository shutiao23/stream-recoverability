# 换成普通整数种子之后的重算：新旧结果对比

背景：按要求去掉所有哈希相关内容，随机种子也改成普通整数。每个缺口掩码、日历平移、条件模拟和重采样都因此重新抽取，当前研究（paper/wrr_tr）的全部实验从头重跑。定义、模型、规则和代码没有改。完整的 186 个宏变化见 `tr_claims.tex` 的新旧对照；本文只列影响结论的部分。

## 1. 预注册终点的判定

| 终点 | 原来 | 重算后 | 变化 |
|---|---|---|---|
| P1 偏差降幅 / 90% 区间覆盖 | 73% / 85.1%，通过 | 72% / 84.8%，**未通过** | 覆盖率跌到 85% 下限之下 |
| P2 保留率增量 | 约 0，未通过 | 约 0，未通过 | 不变 |
| P3 留一区域，长缺口达标比例 | 86%（中位 5.7%），未通过 | 79%（中位 5.6%），未通过 | 不变 |
| P3 澳大利亚风险（日历 / 长缺口） | 12.6% / 17.5% | 13.1% / 17.6% | 不变 |
| P4 趋势 RMSE 降幅 | 76% | 65%（校正定义下 67%，区间 [58, 79]） | 仍通过，但幅度明显下降 |
| N1 风险（日历 / 长缺口，k=1.27） | 4.4% / 5.1% | 4.5% / 5.6%（上界 6.4% / 6.8%） | 仍通过 |
| N2 最难一档覆盖 | 87.9% | 87.4% [85.7, 89.2] | 仍通过 |
| N3 偏差降幅 | 88% | 86% | 仍通过 |
| N4 排序增量（长缺口 / 日历） | 44 / 2 点 | 42 / 2 点 | 描述性 |

## 2. 值得注意的变化

1. **P1 的结论翻转。** 原来的覆盖率 85.1% 贴着下限，换一组随机数就掉到 84.78%。这说明一个以点估计过线与否来判定的终点，对随机数是脆弱的。论文已改为如实报告“未通过：降幅达标，覆盖率略低于下限”。
2. **P4 的幅度对种子敏感。** 降幅在 65%–76% 之间移动，原因是站点趋势误差的平均被少数记录长、误差大的站点（主要是 usgs|13342500）主导。结论方向没变，但正文不应再强调“约四分之三”。
3. **“保留年份”占收益的比例从 77% 降到 60%，区间从 [57, 94] 变成 [33, 95]。** 结论“多数收益来自保留年份”仍成立，但没有以前那么强。要点已改为“多数”。
4. **本地校准所需的组数从 2 增到 8**（长缺口）。真实日历下仍是 2 组即可。迁移一节已改。
5. **k=1 时留一区域的达标比例从 93% 升到 100%**（长缺口，最差区域 6.7%），而 R7a 的该比例从 71% 降到 57%。因子 k 的作用在 R7b 上比以前小，在 R7a 上仍然重要。
6. 热年漏判：丢弃全部年份之外，90% 规则漏掉 22%（原 17%），插补值漏掉 9%（原 5%），多重插补 6%（原 4%）。
7. 流量示范（7Q）的趋势降幅 60%，不变。

## 3. 对论文和研究设计的含义

- 两次测试不再是盲测，主文和 SI 已改成“两个附加资料集上的评估，种子改变后重算”，并在偏差清单第 12 条列出原始数值。
- 这次重抽等于做了一次很粗的“换种子重复”：多数结论稳定，但 P1、P4 的幅度和 P1 的判定会随种子移动。**建议把“多种子重复”作为正式的稳健性分析**，例如对病例生成与模型拟合用 10 个以上的普通整数种子重复，报告各终点的分布，而不是只报一次。这应放在新独立测试之前做。
- 迁移的结论仍然只能称为初步结果，需要在新的、独立的站点上用公开预注册平台（如 OSF）登记后再测一次。

## 4. 还没解决的事

- `plain_seed` 在参数多于 4 个时，前面的参数曾被模 2³² 吃掉（16 处历史调用受影响，位于 scripts/311、312、317、330、334、336、341、342、351、359、360）。已改为：5 个及以上参数改用素数 2³²−5 取模，4 个及以下参数的种子不变，所以当前研究（paper/wrr_tr，最多 4 个参数）的重算结果不受影响。新增 `tests/test_seeds.py`。这些历史脚本若重跑，会得到与改前不同的随机抽样。
- 历史流程（v17 等）的结果只有在重新生成病例表后才能复现原来的表。
- 约 555 个文件名和 10 个目录名仍是十六进制名字，改名会让路径引用失效，需要你决定是否统一改名。
