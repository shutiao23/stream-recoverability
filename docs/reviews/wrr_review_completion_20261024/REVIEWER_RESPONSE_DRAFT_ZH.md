# 对本轮主要意见的回应

1. 将不依赖重建的观测事实提前：96个长期站中20站、35个不完整站年已有完整观测窗口超过完整年纪录。保留测量有效性与无法确定唯一最热年的限制。
2. 保留同等校准的经典随机重建，接受其与D2相近或在前推条件更强的结果；不通过增加模型容量或削弱基线保证D2胜出。
3. 新增整档案统一缺测后再拟合日模型、气候态与残差的实验。邻站在本实验中保持可观测；年度模型和校准不使用目标地区隐藏结果。离线与2010年前训练、2010年后评价分开。
4. 在相同掩码和参考趋势下，交叉两种保留集合及三种年度估计器，用对称MSE分解识别贡献并保留交互，不再使用固定60%的路径归因。
5. 比较独立、共享参数、三年残差块的联合样本，每年边际完全相同。任务校准使用年度拟合及年度区间校准未使用的源组；前推校准另行生成，只使用2010年前误差。覆盖、宽度、区间评分和可用率同时报告，不主张已解决所有前推区间问题。
6. 将估计值、观测下界与未知分开。在已有热年、未来年份和传感器污染情景上报告错误发布、输出损失、漏掉或保留未知的热事件，以及假设污染比例的情景曲线。空气贴合规则只能检验该精确替换压力条件。
7. 实际取得新西兰九站原生资料并检验资格。原质量标准下没有合格完整参考年，故没有宣称独立预测精度验证成功，也没有将未知质量码改成已批准代码。另取得十个元数据候选USGS站的批准日均记录，检验原先选择的观测纪录主张：三站、九个站年的完整批准窗口超出全部批准完整年纪录。参考只有1—3年，不能推断总体发生率或外部重建精度；所有候选及失败保留。
8. 主文重排为五张核心图；旧的年度独立拟合后组合趋势明确标为assembly-only诊断，与新整档案实验分开。代码测试不代替科学结论。
