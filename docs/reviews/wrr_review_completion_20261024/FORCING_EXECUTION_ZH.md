# 全源站驱动与流量对照

美国结果已完成，欧洲扩大采集进行中。所有河温均为已经打开的源档案，不涉及新西兰独立检验。

欧洲资料与恢复概率完成后，`520_review_completion_finish_delivery.py` 自动顺序执行证据汇总、正文与补充 PDF 编译、草稿封包、隔离执行检查、数值核验与交付清单校验。状态写入 `evidence/final_delivery_progress.json`；任何步骤失败即保留日志并停止。已记录的公共注册压缩包保持原字节，不被重新封包；该流程不请求新西兰水温，也不宣称全任务完成。

美国名单固定为全部 319 个可评估 USGS 物理站，按站号排序、不按误差筛选。21 个物理站出现在不同网络的历史输入中，因此保留 340 个网络–站点任务；每个任务使用原始全精度水温、原始气温和原输入时间范围。日模型沿用未标准化 Ridge、alpha=1、原气温滞后及谐波、最少 120 个训练日，排除整个目标年。

`inputs/forcing_full_source_exact/original_core_control_audit.json` 核验 67,316 个病例：可用性无差异，67,297 个共同有限点的最大数值差为 0。各臂均保留全部病例，包括输入不可用的病例。Daymet 的 319 站均成功取得；流量使用已有源档案，矛盾重复日期和负值保持不可用。

单位为 °C；失败定义为绝对误差超过 0.5°C。Daymet 和流量比较中，逐站 MAE 不变或改善的比例分别为 45.8% 和 71.3%。全分层的 MAE、偏差、失败率、隐藏日误差及逐站变化保存在 `paired_summary.csv`。

另按原源域连接组做 2,000 次成组重抽，保持两臂病例配对。气温层危险病例中，流量的相对 MAE 降幅为 12.08%，95% 分位区间为 8.34%–16.42%（107 组）；Daymet 为 −3.22%，区间 −5.45%–−1.30%（112 组）。完整结果见 `paired_group_bootstrap.csv`。这些区间仅反映固定、共同可用病例的组构成敏感性，不包含新的掩码、模型拟合或新气候不确定性。

Daymet 是日最高、最低气温的中点，原 POWER 是日平均，日聚合和空间产品同时改变；缺失的闰年 12 月 31 日及其影响的滞后不补造。流量采用 log1p 及 0、1、3、7 日滞后。结果支持流量在这组配对病例中的增量，不支持“提高空间分辨率必然消除峰值冷偏”。这里重新拟合的是日补全模型，没有使用替代驱动重新训练所有年度分布回归或发布分类器，也不是 20 次掩码重复。

旧 35 站的标准化 Ridge 试验及日历滞后修正材料保留；全源站结果采用原模型配方，不能把两个试验的差异全部归因于新增站点。

欧洲扩大名单固定为全部 262 个源站。原先缺少坐标的法国九站已由官方目录、既有目录及 CRS84 几何核实补齐；不按误差换站。原采集进程沿用其开始时的坐标快照，结束后自动补取这九站气温。使用同样的原模型控制、ERA5-Land 日均气温及公开 API，已有长缓存复用；新请求只覆盖站点实际历史及前 14 日滞后支持。POWER 与 ERA5-Land 日期约定保持原样，不能称完全同钟的分辨率实验。扩展采集遇到的服务配额、等待与不可用原因均保留，进行中计数以 `europe_full_source_exact/acquisition_progress.json` 为准，未完成子集不写成欧洲总体结果。服务的长时间范围请求折算为多次 API 调用，遵守[官方配额与计费说明](https://open-meteo.com/en/pricing)。

## 河流类型元数据的补充

USGS 14158500 的官方名称明确为 Clear Lake 出口，已核实为一处机构标注的湖泊出口，其余 580 站仍未知。源拟合种子 0 下，该站真实日历 32 例无超过 0.5°C 的失败，受控缺口 108 例中失败率 4.63%；这是单站描述，不作类型间因果或总体风险推断，也不改变原源预测。

## 恢复概率重算

恢复概率现已随驱动重算：每个目标年同时排除目标年与残差验证年的全部水温标签，用相同未标准化 Ridge 配方取得折外残差；再重算暖季残差均值、方差、自相关和 Gaussian AR1 窗口模型的概率。原始水温气候态、训练峰窗和缺口几何不变。每条概率预测各自日模型的失败；表中的实际与预测风险在同一有限支持集计算，不把不同臂的不同失败目标当作同一组标签。原年度 D2 与发布分类器均未重训。
