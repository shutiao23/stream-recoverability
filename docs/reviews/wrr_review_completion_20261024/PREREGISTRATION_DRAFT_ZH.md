# 独立检验公开注册材料（待提交）

此文件是可审查的方案草稿，不是已完成的公开注册。机器可读版本与代码包位于 `results/wrr_review_completion_20261024/independent_study/`。作者、机构、资助和 OSF/Zenodo 字段由用户填写。只有平台公开登记且协议、代码和固定模型附件匹配后，才能下载候选站的水温值。

## 人群与资格

原首选为新西兰 Horizons 区域委员会。对 WaterTemperature 集合 58 个站的测量类型、日期范围及站点属性核查已完成：当前公开档案没有满足四个完整七月至六月热年时间支持的潜在合格站。因此在任何新水温值之前，固定替补为 Greater Wellington 的公开连续档案；不看模型误差再更换机构。没有请求两者的河温观测。

排除湖泊、海岸、地下水及低频水质抽样。日值必须是机构日均值，或有足够完整日内观测并通过固定质量检查的日聚合。每个目标站至少四个完整的七月至六月热年；季节用训练气候确定。按连通河网及共享供体保守合并独立组，排除本研究已有站及已知连通网络。Greater Wellington 的 SurfaceWaterZone 先用于保守合并，管理区数不自动等于独立水文组数。不得因预测表现不好补站。

替补档案已核完 218 个目录站，按保守的河流类型及连通元数据要求固定 9 个潜在站，合并为 3 个 SurfaceWaterZone。名单及采集方案位于 `independent_study/greater_wellington/registration_roster.csv` 和 `acquisition_plan.json`；不是九个已证实拥有完整参照年的站。水温供体只在合并组内共享。跨区天气和误差的独立/交换性仍是假设，3 个区的组自助只支持失败检测与描述性研究，不支持一般迁移保证。

所有候选 TimeRange 的明确偏移均为 UTC+12，与 NEMS 的 NZST 一致。主参照日要求原生规则间隔完整、每个观测的机构质量码均为 600；每月只根据时间戳的众数间隔确定预期频率（不超过 60 分钟，平手取较短，须整除一天），不插值、不接受未知或合成质量。日内均值描述报告序列，不是无仪器误差的物理真值。日均气温固定为 ERA5-Land 的 24 个完整小时按同一 NZST 日聚合。河温截点为 2026-07-01 00:00 NZST，不包括当期未完整热年。完整参照年数只能在登记后的固定质控中判定；不足四年的站报告不合格，不放宽标准补站。

旧 `data/`、`data_versions/` 的机构/站名及新西兰元数据搜索未发现候选的先前记录，核查范围写入 `prior_access_audit.json`；这不是对其他账户或全部过去人类知识的证明。最初的 1,071 条通用目录记录不是合格河温名单。

## 方法

源域固定全局候选已经拟合，存于 `deployment/global_source_candidate.joblib`；其 `candidate.json` 固定四个独立组角色、种子 0、点值与阈值。单值发布对象为 D2 校正中位数，因为风险分类器学的是该值的失败；原始或校正随机回归作为估计对照，不能直接套用 D2 的风险分数。比较对象还包括 plug-in、MOVE.1 与泛函去偏。单值发布阈值为预测失败概率 ≤0.1；单独报告的批量用途必须另加逐例上限 0.3。0.5°C 容差、30/60/90 天缺口、真实日历生成方式、轨迹数、分组和不可用值处理均随代码包固定。目标区域标签不参与无标签方法选择。

固定源权重指年度模型、失败分类器和区间偏移。每日补全的局地系数、气候态和残差按固定配方用目标站其他历史年份拟合；被评估整年不进入这些拟合。这是离线修复而非实时预报，其他较晚历史年份可以使用；没有宣称完全无目标站历史拟合。

## 终点和判定

| 终点 | 判定 |
|---|---|
| E1，主要 | 受控长缺口下实际风险 ≤6%，独立组自助单侧 95% 上界 ≤8%，必须非空放行 |
| E2，共同主要 | 放行至少 20 例的组中，风险 >10% 的组比例 ≤10%；无合格组不能判通过 |
| E3，次要 | 决策时峰窗被遮 ≥50% 病例的 90% 覆盖率在 85%–95%，并报区间得分和宽度 |
| E4，次要 | 同一危险层的 MAE 相对 plug-in 降低至少 20%，以共同可用病例配对比较 |
| E5，描述性 | 10 个本地有标签独立组下的认证留存、证书状态及最差组风险；固定三组人群无法实施，预先报告不可用 |

E1 和 E2 必须同时通过。真实日历风险、分层、少量标签曲线均如实报告。E2 是组比例点估计标准，并非每组风险的同时置信保证。缺失标签、不支持预测和空放行单列；不当作零风险成功。次要推断的多重比较用 Holm 校正。

E5 除原有独立组有界损失证书外，还包含有标签 WSR RCPS 和一般损失半监督 RCPS；后者须使用不同的有标签、无标签校准、最终测试组。独立无标签组不够时报告不能实施，不重复使用同一组。条件保形的 LAC 保守/随机化预测集合只作辅助比较，其覆盖和误放频率不替代放行后条件风险。批量方法不是本次主要终点，若额外纳入，所有源校准参数必须在公开协议中固定。

## 样本量与停止

源域独立组上的经验模拟只用于规划，不证明新气候区的功效。最终代码自动输出独立组数 20–200 的 E1/E2 联合通过概率；没有达到 80% 的规模就不推荐“足够”的样本量。确定名单后一次性获取全部合格站，按元数据预定的停止标准结束；不得因表现不好继续招募。样本不足时按失败检测或描述性研究报告。

实际规划已经覆盖 20 个源种子，每个组数预算共 40,000 次模拟。20/40/100/200 个独立组的等权种子混合联合通过率为 38.9%/30.6%/19.2%/13.4%，所有测试规模均未达到 80%；200 组时源种子概率的经验 2.5%–97.5% 分位约为 0.024%–60.9%。源种子之间的变异不可忽略，这些分位不是新气候的功效置信区间。当前草稿定位为固定候选的失败检测与适用边界研究，或先在源域改进校准并重新拟定公开协议；不能把它表述为已有充分功效的确认研究。

## 预写结果段

通过版本：小队列达到了事先规定的样本描述性标准。仅三个保守管理区不足以据组自助上界建立总体 95% 风险控制、一般气候迁移或任意单个站年的条件风险保证。

失败版本：源域校准未达到预先规定的描述性标准。我们报告偏离方向、留存与校准曲线；三组下十标签组比较不可用，不能据此给出足够的本地标签数。结果不通过也不更换数据或方法重算同一研究。

## 平台提交清单

用户自行填写研究者姓名、机构、通讯邮箱、资助、利益声明和平台链接；最终元数据名单、代码和拟合模型需随方案附上。代码包带文件 SHA256 清单，`bundle_inventory.json` 另记压缩包摘要。提交后记录 OSF 公开 URL 及平台登记时间。`python scripts/472_review_completion_prereg.py --osf-registration <公开注册ID>` 只检查公开记录；加 `--verify-attachments` 才会核验注册存档中的协议 JSON、清单 JSON 和代码/模型包的实际字节。可编辑原项目的同名附件不算匹配。该命令不会重新打包或下载水温。

注册后按 496（原生日内水温及质量采集）、497（同钟气温、固定源病例生成）、495（固定源权重及 0.1 阈值、E1–E4 与记分卡）的顺序运行。公共登记尚缺，所以当前入口会在任何河温请求前停止。日内与质量解析目前只在合成数据上验证，天气小时接口在两天无河温请求的检查中验证；实际登记后若接口或参照资格不满足，按不可评价报告。E5 因三组上限预先不可实施。具体命令见 [独立检验执行说明](INDEPENDENT_EXECUTION_ZH.md)。
