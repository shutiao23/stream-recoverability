# budget_full — v15/W2.1 within-duration budget sweep (WORKPLAN_v15.md Step 2.1)

Complete decision-layer sweep replacing the single-budget P0/P1 tables:

- Budgets: B in {5, 10, 20, 30, 50}% (protocol v5 C1 registers {10, 20, 30}%;
  the extra points bracket the registered range).
- Predictors: the full Tier-0 suite — diff, risk, neg_risk (−risk), duration,
  r6_diff, default_difficulty, rh_error, rh_benefit, amplitude, sd, global —
  plus the within-stratum **oracle** (top-k by realized benefit) and **random**
  brackets, and the **capture** rate (treated_mean − random)/(oracle − random).
- Grid: both panels × durations {7, 14, 30, 60, 90, 180} d, direct placements.

## Files

- `budget_full.csv` — point estimates: n, k, stratum_mean, oracle, random,
  and per predictor treated_mean / harmful_rate / capture.
- `budget_full_ci.csv` — 95% network-cluster bootstrap CIs (2,000 draws,
  seed 20260903; within provider strata US/CZ/NO on the second panel) for the
  oracle and the six main predictors {diff, risk, neg_risk, duration, r6_diff,
  default_difficulty} at every (panel, duration, budget) cell.

## Conventions

- Selection: descending predicted value, tie-break jitter seeded by
  `f"{panel}|{horizon}|{predictor}"` (identical scheme to scripts/143), so
  every budget's top-k set is a prefix of the B = 0.20 set; the B = 0.20
  column reproduces `results/v14/p1_baselines/budget_within_duration.csv`
  exactly (120/120 rows checked, max |Δ| < 1e−9).
- Oracle = mean realized benefit of the top-k placements (k = round(B·n));
  random = mean over 200 seeded draws of a k-of-n sample without replacement
  (seed 20260905, matching `results/v14/p5_mechanism/budget_brackets.csv`).
- neg_risk is the same bit-identical v13 risk column with sign flipped
  (ρ(−risk) = −ρ(risk); §2.4 of the manuscript).
