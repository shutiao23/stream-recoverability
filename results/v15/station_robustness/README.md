# station_robustness — v15/W2.2 robustness of the station-level crossing (WORKPLAN_v15.md Step 2.2)

Supplements `results/v14/p5_mechanism/station_crossings.csv` (scripts/152),
which kept only stations with a single interpolable sign change in their own
benefit curve (b[0] > 0 and b[-1] < 0). Three CSVs:

## A. `station_classification.csv` — exclusion counts and destinations

| panel | class | n | share |
| --- | --- | --- | --- |
| first | included (single crossing) | 188 | 85.8% |
| first | excluded: never crosses by 365 d (benefit ≥ 0 at every grid point) | 31 | 14.2% |
| second | included (single crossing) | 210 | 93.8% |
| second | excluded: never crosses by 365 d | 14 | 6.3% |

No station is excluded for starting negative (no station has negative mean
benefit at 7 d), and **no included station re-crosses positive after its
first negative grid point** — every retained curve is a single crossing, so
the 152 filter is exact rather than approximate. The excluded stations are
the law's late-crossing tail (reconstruction stays net-beneficial through
365 d at those stations), not a hazard class: their exclusion is reported
here rather than left implicit. Spearman on the included set reproduces 152
exactly (+0.243 first / +0.411 second).

## B. `provider_strata.csv` — the crossing Spearman by provider

Second panel (prospective): chmi 0.342 (n = 69, p = 0.004),
nve_hydapi 0.430 (n = 38, p = 0.007), usgs 0.365 (n = 103, p < 0.001) —
positive in all three providers, so the pooled +0.411 is not a
single-provider artifact. First panel (development, descriptive): gkd_bayern
0.300 (p = 0.034), usgs 0.196 (p = 0.094), arso −0.066 (p = 0.69),
lubw −0.016 (p = 0.96), foen 0.217 (p = 0.58) — the pooled +0.243 is driven
by the German and US networks and is not uniform across the five providers;
this is reported honestly as a development-panel boundary (the prospective
panel is the confirmatory evidence).

## C. `partial_correlations.csv` — confounding check

controlling for the station's signal amplitude and residual SD (P1

| panel | control | partial ρ | p | zero-order on same subset |
| --- | --- | --- | --- | --- |
| first | amplitude | +0.426 | < 0.001 | +0.164 (p = 0.06) |
| first | sd | +0.348 | < 0.001 | |
| first | amplitude + sd | +0.365 | < 0.001 | |
| second | amplitude | +0.608 | < 0.001 | +0.435 (p < 0.001) |
| second | sd | +0.489 | < 0.001 | |
| second | amplitude + sd | +0.563 | < 0.001 | |

The association is not mediated by the station's signal amplitude or residual
variance — the partial correlation is at or above the zero-order estimate in
every control, so the station-level prediction of the law survives the
confounding check (a suppressor pattern: amplitude/sd explain variance that
opposes the clim-MAE signal, and removing it strengthens the association).
The first-panel zero-order weakens on the covariate-complete subset
(+0.164 vs +0.243 on all 188), which is reported with the subset n.
