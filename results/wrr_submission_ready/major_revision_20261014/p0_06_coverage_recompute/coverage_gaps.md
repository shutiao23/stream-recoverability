## 4. Record-span / complete-year mismatches

- `first_year`/`last_year` disagree with `trusted_river_complete_years.csv`: **0 stations** (v17 panel only; wave-2 has no trusted file).
- `n_complete_years` not reproduced by the per-row recount rule: **113 station rows** (v17: `sum(full_calendar_year)`; wave-2: the `len(values) >= year_length - 1` variant).

| panel | provider | n station rows with a recount mismatch |
|---|---|---|
| wave2_confirmation | usgs | 113 |

Wave-2 station completeness is defined by a rule evaluated on the per-station series *before* it is widened into `daily_wide_temperature.csv`; the widened file cannot restore the row count the rule tests, so the wave-2 count is only reproducible under a named convention. Two recounts are carried in the coverage table:

- `n_complete_years_recount_ge_expm1` — len(values) >= year_length - 1 (rule as written): agrees with `station_eligibility.csv:n_complete_years` for **51 / 164** wave-2 station rows.
- `n_complete_years_recount_all_days` — every calendar day present (strict): agrees with `station_eligibility.csv:n_complete_years` for **162 / 164** wave-2 station rows.

Neither recount is silently substituted for the project value: `final_coverage_table.csv:n_complete_years` is always the project artifact.


## 5. Columns the review asked for that do not exist in the named artifacts

- `wave2_inputs_manifest.csv` has no `first_year`/`last_year`/`n_complete_years` column: the record span is recomputed from `daily_wide_temperature.csv` and the complete-year count is taken from the sibling `station_eligibility.csv`.
- Neither wave-2 artifact carries `regulation_status` or `donor_regime`; both are read from `p0_07_wave2_confirmation/wave2_cases.parquet` and the source column is named in the coverage table.
- `metadata/data_rights.csv` has no row for `hubeau` or `uk_ea`, so no repository-level licence entry exists for the two non-USGS wave-2 providers.
- There is no water-temperature record-span table anywhere in the repository. The only `1981 to 2026` span in the submission is the air-temperature forcing: `paper/wrr/wrr_supporting_information.tex` line 94 reads "Daily 2\,m air temperature is NASA POWER (MERRA-2), 1 January 1981 to 31 August 2026 ... 16{,}679 days for each of the 457 stations". The water-temperature span per station is available only as `first_year`/`last_year` in this table, with the source column named per row.
