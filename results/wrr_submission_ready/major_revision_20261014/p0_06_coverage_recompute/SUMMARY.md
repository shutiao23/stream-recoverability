### Limitations of this recompute

1. Reproducing the step-2 contrast requires the same tie-break RNG stream and the same fold assignment as the stored run; both are re-implemented here from the frozen protocol, not called from the original module. Agreement to 1e-9 therefore tests the *implementation*, not the protocol choice.
2. The wave-2 complete-year count is only reproducible under a named convention. `final_coverage_table.csv` carries both recounts and the project value side by side.
3. `metadata/data_rights.csv` has no row for `hubeau` or `uk_ea`; their licence route is recorded only in `measurement_provenance_dictionary.csv`.
4. The wave-2 interval is reproduced with the same bootstrap seed as the stored run. An independent resampler with an unrelated seed moves the interval by O(0.05) pp, which is Monte-Carlo noise in the reported 2000-draw interval, not a discrepancy in the contrast.
