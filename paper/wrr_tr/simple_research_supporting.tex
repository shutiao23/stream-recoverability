\section{Whole-archive supplements}
The full MSE cells, interactions, matched estimator contrasts, unavailable cases and task calibration sources are stored in results/whole\_archive. Independent source groups, rather than mask repetitions, determine calibration support. Forward task calibration ends before 2010. The four error-direction illustration uses a single synthetic half-degree common shock on thirty annual values; it is an algebraic sensitivity, not new river evidence. The evaluation-only error covariance uses hidden reference values solely for diagnosis and is never a deployment estimator. Gaussian-tail extrapolation leaves the central stored quantiles unchanged but changes the marginal tails, and is reported separately from the fixed-marginal rank comparison.
