\section{Poudre Water Quality Network reference qualification}
A metadata-only screen selected four locations whose source periods span at least four UTC years in 2020--2024. The selected sites share one watershed; older USGS station metadata from the same river had already been encountered, and exact prior-network connections remain unresolved. Before opening temperatures, we fixed a criterion of 96 unique quarter-hour UTC observations per day, finite post-processing values in degrees Celsius and author PASS status. The author metadata describes the unit as degrees C, while the source file uses C; that notation mapping was recorded after inspecting unit labels and before calculating completeness. None of the 20 site-years qualifies; each lacks at least 28 distinct quarter-hour timestamps even before the value and quality filters. Thus no recovery model was scored. Source files contain other sites and parameters that were not qualified here. The authors note that technician calibration records were not collected for 2019--2021; PASS flags do not prove error-free sensors or independent climates. Source: Struthers et al. (2026), DOI 10.4211/hs.521e317e189e498581d0aaa08c3f32bc, CC BY 4.0.
