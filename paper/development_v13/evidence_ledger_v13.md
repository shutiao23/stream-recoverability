v13 disposition, its evidence role, and its location in the v13 package.
Column conventions:

- **Status**: retained / corrected / re-verified / demoted to SI / removed /
  relabeled. "Corrected" = the number changed because the v12 text was wrong
  (not because evidence changed). "Re-verified" = value reproduced by a
  v13 analysis agent under `results/revision_v13/` (where those agents had
  not yet written at the time of this ledger, the v12 artifact value stands

  (computed on already-scored panels during revision v12) / v13
  harmonization (convention or baseline choice adopted in v13) / future
  preregistered (protocol v4 only).

  `figure_plan_v13.md`; SI sections S1–S12; `protocol_v4.md` clauses.
