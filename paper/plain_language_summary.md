# Plain Language Summary

Rivers are often monitored every day, but sensors still fail. Recoverability may be predictable before choosing a model. We separate three sources already present in the monitoring record: the repeating seasonal cycle, temperature anomalies shared with surviving stations, and the target station's own short-term memory.

Using only 2006--2015, an equation predicts recovery skill for gaps from 1 to 365 days. It classifies two Upper Jinsha stations as donor-dominated, with nearly flat long-gap predictions, and one as memory-dominated, with skill that decays as gaps lengthen. Fixed artificial outages then test these predictions. Validation favours a simple neighbour-station regression; unstable deep runs are excluded rather than used to claim that deep learning is ineffective.

A second connected river panel is reserved for an evaluate-once test. The intended output is a network-design rule for deciding which sensors need protection, how long a gap may remain recoverable, and whether adding a donor sensor is likely to help. No safe operational fill length is claimed without a predeclared error threshold.
