# Plain Language Summary

Rivers are often monitored every day for water temperature, flow, and water level. Those records still contain gaps: a sensor can fail for days, several variables at one site can drop out together, or neighbouring stations can go offline at the same time. Filling those gaps is not the same problem as predicting a few randomly missing points, because the useful information that remains depends on how long the gap lasts and on which other measurements are still working.

This study asks when daily stream temperature at three stations on the upper Jinsha River can still be reconstructed. It treats models as tools for finding three boundaries: how long a gap can become, which surviving measurements still help, and which station failures hurt the whole network. Early validation comparisons show that a simple neighbour-station regression can outperform more complex imputation models. That is a hydrological result to test, not a reason to discard the simple model.

The evaluation is locked before formal performance numbers are read. This draft therefore reports the locked design, data rights, and the validation-only ranking, and it does not claim a safe fill length or that any new model is generally best.
