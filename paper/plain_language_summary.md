# Plain Language Summary

Reservoir releases can make downstream water temperatures less seasonal and more persistent. We tested whether those changes can help decide which observations reconstruct an outage in a temperature record. We temporarily hid known daily values at three Jinsha River stations and five Chattahoochee River stations, then compared information from other stations with information at the edges of each gap. In both rivers, the station closest below a major dam depended more on its own boundaries, while farther stations depended more on simultaneous network observations. That pattern is a case-study screen, not proof that a dam caused the pattern or that the same rule works everywhere. The Jinsha files have no per-value quality codes, overlapping gaps are not independent samples, and the Chattahoochee model scores were chosen after the held-out run was already seen. Across 335 United States gauges, the same indicator weakened with distance below major dams but did not classify dams nationwide; a previously reported national score is not a valid classifier. The indicator can help inspect monitoring vulnerability in a documented network after local testing. It does not identify a safe gap length to reconstruct.
