# Cover letter (Water Resources Research)

**Manuscript title.** Predicting Stream-Temperature Recoverability from Monitoring-Network Information Budgets

**Dear Editors,**

We submit a protocol-locked test of whether daily stream-temperature recoverability can be predicted from a monitoring network's observed covariance structure before any imputation model is trained. A train-only budget separates seasonal structure, simultaneous donor-station anomaly covariance, and local anomaly memory. Fixed outages and stable learners test the resulting station typology and information ceiling.

**What is complete in this repository version.** The executable design freeze (`design_freeze_v4`), split QC fields, dual-frontier and donor-C falsification contracts, MIT software licence, data-rights matrix, environment lock, confirmatory feasibility gate (no once-lock, no confirmatory skill), independence audits of validation anchors and event matching, NASA POWER $R_s$ rebuild of the internal Group D channel, and the AGU file set in `paper/` (manuscript with empty Results, extended methods, SI index, Key Points, plain-language summary, and figure captions). Descriptive Figure 1–2 and Table 1 may exist; result Figures 3–8 are omitted until current-protocol formal artifacts exist.

**What is not claimed.** This cover letter does not assert a formal frontier day or that the proposed model outperforms donor regression. Validation-only ranks favour donor regression. Required deep seeds selecting before epoch 50 are labelled `training_unstable` and cannot support a claim that deep learning is ineffective. CSDI is a reduced probabilistic diagnostic, not a frontier model. Pre-freeze files under `results/formal/` remain invalid for inference.

**Data access.** Yearbook hydrology, CMA sunshine/humidity, and WMO/CMA series that match GSOD are **not** open. Reviewer access is through AGU GEMS Data Files for Peer Review (editor-mediated). NASA POWER shortwave used for the internal Group D channel is a generally citable US-government product. USGS confirmatory data are not opened until roster freeze.

**External confirmation design.** One Upper-to-Middle Chattahoochee mainstem network panel (not five basins; not Lower Chattahoochee; not nested-point M1), evaluate once after roster freeze.

We ask that any review treat missing numerical Results as an incomplete evidence package rather than as implied performance.
