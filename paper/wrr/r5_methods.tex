\subsection{Conditional H30 distributions}

A further probability-reference budget compares two air-conditioned CSDI widths using old group-disjoint data only. Fitting has 3,469 years, while thirty old validation groups each provide five predeclared peak, boundary and fragmented masks. Early stopping uses masked-water validation loss; configuration selection uses H30 CRPS in degrees Celsius. Source normalization excludes the target year, and observed water remains fixed. We report compute and 8/16/32-sample sensitivity. Distribution samples are shared across reconstruction points so direct failure probability is computed for each delivered point before testing added windows. Calibration and use decisions retain their independent roles and original pools.
